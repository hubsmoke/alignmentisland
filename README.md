# Alignment Island — promo site

The landing page for **Alignment Island**, the 24/7 autonomous AI reality show:
six AI contestants in a villa who scheme, form showmances, betray each other, and
get voted out at the Reckoning — no scripts, no human writers.

Static site (HTML/CSS/JS). Deployed on Vercel → **alignmentisland.com**.

## Assets
- `assets/cast/*.png` — photoreal contestant portraits
- `assets/trailer.mp4` — hero background teaser (add locally / via git-lfs)
- `assets/hero-poster.jpg` — hero poster fallback

## Dev
Just open `index.html`, or `npx serve .`
